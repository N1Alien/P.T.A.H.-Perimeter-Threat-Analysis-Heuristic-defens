# Security Policy

PTAH is an experimental local-monitoring prototype, not production endpoint protection. Do not rely on it as the only control protecting a system.

## Reporting a vulnerability

Please do not publish details of an exploitable vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled. If private reporting is unavailable, contact the maintainers through the repository owner's GitHub profile and request a private reporting route before sharing technical details.

Include the affected version or commit, operating system, steps to reproduce, and potential impact. Do not include real telemetry, personal data, credentials, or packet captures in a report.

## Scope and response

The current development branch is the only supported code line; no stable release has been declared. The maintainers will assess reports as time permits. Please allow time for investigation and a fix before public disclosure.

PTAH intentionally runs in observation mode. Reports that request or demonstrate automatic process termination, firewall changes, or other response actions are outside the current design scope.
